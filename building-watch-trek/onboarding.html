1. One-time setup

About 45 minutes total, most of it Richard's. Do these in order.

flowchart TD
  subgraph SC[Senior Chief]
    A1[Create Sheet: Building Watch Data] --> A2[Share Sheet with Richard as Editor]
    A3[Create calendar: Facilities, In the Building] --> A4[Share with Richard: Make changes and manage sharing]
  end
  subgraph RD[Richard]
    B1[Google Cloud: create sign-in client, publish app] --> B2[Apps Script: paste 3 files, fill SETUP]
    B2 --> B3[Run setup and approve permissions]
    B3 --> B4[Deploy as web app: Me, Anyone]
    B4 --> B5[config.js: script URL and client ID]
    B5 --> B6[GitHub Pages on]
  end
  A2 --> B2
  A4 --> B2
  B6 --> C1[Richard signs in, Test connection]
  C1 --> C2[Add Senior Chief as Admin and Building manager]
  C2 --> C3[Add sailors with invitations]
  1. Senior Chief
    Make the Sheet and the calendar and share both with Richard. Send him the Sheet address and the Calendar ID.
  2. Richard
    Create the Google sign-in client in Google Cloud. Publish it to production so any Google account can sign in. Copy the Client ID.
  3. Richard
    Paste the script (Code.gs, Core.gs, appsscript.json), fill in the four SETUP values, run setup, approve the permission screens.
  4. Richard
    Deploy as a web app: execute as Me, access Anyone. Copy the URL ending in /exec.
  5. Richard
    Fill in config.js on GitHub with the script URL and Client ID, then turn on GitHub Pages.
  6. Richard
    Sign in and test. Admin, Data storage, Test connection should show Senior Chief's Sheet and calendar.
  7. Admin
    Add Senior Chief as Admin and set him as Building manager. Then add the sailors.

2. Getting a sailor in

Only emails an admin adds can sign in. Nobody types a password into the app; Google handles that.

flowchart TD
  A[Admin adds sailor's Google email in People and roles] --> B[App shares the main calendar with them]
  B --> C[App emails the invitation link]
  C --> D[Sailor opens link and signs in with Google]
  D --> E{Is that exact email on the list?}
  E -- No --> F[No access screen shows the account used]
  F --> G[Admin fixes the email, or sailor switches accounts]
  G --> D
  E -- Yes --> H[Sailor enters rank, name, phone]
  H --> I[Paints time on My week and saves]
  I --> J[Optional: adds own calendar in My settings]
  J --> K[Optional: adds Google account to iPhone Calendar]
  1. Admin adds the email. Use the address the sailor will sign in with. A Gmail is easiest. Anyone can turn an existing email into a Google account at accounts.google.com/signup without getting a new inbox.
  2. Sailor signs in from the email. If it says "no access," the screen shows which account they used. Match it in People and roles.
  3. Profile, then paint. Rank and name, phone, then drag over the times they'll be in the building and press Save.
  4. Own calendar (optional). In My settings, paste the secret iCal link from Google, iPhone or Outlook so their existing events show as striped blocks while they paint. Only they see the titles.

3. A normal week

flowchart TD
  A[Admin emails the shop: enter next week's time] --> B[Sailors paint their time and save]
  B --> C[Main calendar fills with In bldg blocks]
  C --> D[Admin opens Watch bill, drags to assign standers]
  D --> E[Each stander gets a private calendar invitation]
  E --> F[On watch: check off duties]
  F --> G[Log maintenance workers in and out]
  G --> H{Finished? Follow-up? New problems?}
  H -- Finished --> I[Linked request closes]
  H -- Follow-up --> J[Shows on Needs follow-up]
  H -- New problem --> K[New service request opens]
  I --> L[Reports: pick dates, download]
  J --> L
  K --> L

When Senior Chief is away, any admin names an acting manager with dates in Admin, Who's in charge. The acting manager gets admin rights for exactly those dates.

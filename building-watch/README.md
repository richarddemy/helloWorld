# Building Watch

Prototype for tracking who is in the building and assigning facilities tasks.

- **Sailor view:** drag on the week grid to mark when you will be in the building.
- **Senior Chief view:** coverage heatmap, tap a slot to see who is in, and ranked assignment suggestions (in building, fewest tasks this month, matching skill).

Sample data only. Nothing is sent to Google Calendar yet. Next step: Google Apps Script web app that writes to a shared "In the Building" calendar and sends private invites for assignments.

Open `index.html` in a browser, or view via GitHub Pages.

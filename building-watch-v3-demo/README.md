# Building Watch V3 — leadership preview

This is a public, standalone, sample-data-only interactive mockup based on the uploaded Hostinger v3 Building Watch application. The real Hostinger PHP/MariaDB backend is **not included** and no Google authentication is performed.

- Main preview: `index.html#home`
- Staff sign-in demo (role selection, no credentials): `index.html#signin`
- Contractor QR check-in walkthrough: `index.html#visitor`
- Maintenance operations: `index.html#staff` then Maintenance log

All sample changes remain in browser localStorage. CSV export is simulated. No email, SMS, GPS or Google Calendar calls. Do not enter real personnel data.

The downloadable full v3 demo adaptation is supplied separately in this ChatGPT session.
